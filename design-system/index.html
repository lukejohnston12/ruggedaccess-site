Tokens and components for ruggedaccess.org. Source lives in _includes/css/, ordered tokens → base → layout → atoms → molecules → organisms → utilities.

Color

Ink, olive and blaze are sampled directly from the logo artwork. Bone is the warm canvas pulled from the desert camo. Components never reference these primitives; they use semantic tokens such as --color-text and --color-accent.

Contrast rules: blaze fills always carry ink text (6.3:1). Orange text on bone uses --blaze-700 (4.7:1). Body text on olive sections uses bone (7:1).

Typography

Barlow Condensed (display) echoes the condensed lettering in the logos. Barlow keeps body copy readable. IBM Plex Mono handles labels, coordinates and specs: the field-notes voice.
